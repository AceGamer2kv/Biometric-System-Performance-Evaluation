## 📌 Overview

This project implements an empirical evaluation of biometric matcher performance on the **Fingerprint Verification Competition (FVC2004)** benchmark dataset. It calculates standard biometric error metrics, evaluates operational decision tradeoffs, and generates publication-quality academic visualizations:

- **Similarity Score Distributions:** Genuine vs. Impostor probability density functions and decision overlap ambiguity.
- **Error Metric Sweep:** False Acceptance Rate (FAR), False Rejection Rate (FRR), and True Acceptance Rate (TAR) across thresholds $t \in [0.00, 1.00]$.
- **Equal Error Rate (EER):** Computed via discrete grid search and continuous linear interpolation.
- **Receiver Operating Characteristic (ROC):** Accuracy evaluation and Area Under the Curve (AUC) numerical integration.
- **Detection Error Tradeoff (DET):** Logarithmic scale error visualization across operational regimes.
- **Operational Deployments:** Optimization profiles for **High-Security** ($\text{FAR} \le 0.1\%$) and **High-Convenience** ($\text{FRR} \le 1.0\%$) applications.

All executable source scripts reside in the `src/` directory.

## 🚀 Execution Workflow

The scripts are located inside the `src/` directory and must be executed in the following order:

```
[ Step 1: Fetch/Prepare Data ]               [ Step 2: Analyze & Visualize ]
   src/fetch_fvc2004_dataset.py       ──►       src/lab3_biometrics_analysis.py
 (Outputs: biometric_scores_fvc2004.csv)       (Outputs: metrics CSV & 5 PNG charts)
```

---

### 1️⃣ Run First: Fetch or Generate Dataset (`src/fetch_fvc2004_dataset.py`)

Run `fetch_fvc2004_dataset.py` first to retrieve or generate the standardized FVC2004 similarity scores:

#### **From the project root directory:**

```bash
python src/fetch_fvc2004_dataset.py
```

_(Or from within `src/`: `cd src` then `python fetch_fvc2004_dataset.py`)_

#### What this step does:

- Attempts to download the official standardized FVC2004 similarity score dataset from the remote repository.
- If offline or if the remote endpoint is unavailable, it automatically falls back to generating the calibrated FVC2004 optical sensor benchmark distributions locally:
  - **2,800 Genuine Pairs** ($100 \text{ fingers} \times \binom{8}{2} = 2,800$ comparisons).
  - **4,950 Impostor Pairs** ($\binom{100}{2} = 4,950$ cross-finger comparisons).
  - **Total:** 7,750 comparison scores normalized to $[0.0, 1.0]$.
- **Output Generated:** `src/biometric_scores_fvc2004.csv`

---

### 2️⃣ Run Last: Biometric Performance Analysis (`src/lab3_biometrics_analysis.py`)

Once the dataset CSV is available, run `lab3_biometrics_analysis.py` as the final script:

#### **From the project root directory:**

```bash
python src/lab3_biometrics_analysis.py
```

_(Or from within `src/`: `cd src` then `python lab3_biometrics_analysis.py`)_

#### What this step does:

1. **Loads the Dataset:** Reads `src/biometric_scores_fvc2004.csv` (or generates it dynamically if missing).
2. **Statistical Score Summary:** Computes sample sizes, means, standard deviations, medians, and score ranges for genuine vs. impostor scores.
3. **Threshold Sweeping:** Evaluates 201 threshold steps ($t = 0.00$ to $1.00$ in increments of $0.005$) to record FAR, FRR, and TAR.
4. **Calculates Equal Error Rate (EER):**
   - Discrete search minimum difference point ($t_{\text{EER}}$).
   - Continuous linear interpolation between boundary points for exact $t_{\text{EER}}$ and EER percentage.
5. **Computes ROC AUC:** Numerical integration using the trapezoidal rule over the ROC curve ($\text{FAR}$ vs. $\text{TAR}$).
6. **Optimizes Operational Thresholds:**
   - **High-Security Profile:** Enforces $\text{FAR} \le 0.1\%$ ($0.001$).
   - **High-Convenience Profile:** Enforces $\text{FRR} \le 1.0\%$ ($0.010$).
7. **Exports Metrics & High-Resolution Figures:** Writes a detailed metrics CSV and 5 publication-ready PNG plots (300 DPI) inside `src/`.

## ❓ Troubleshooting

- **PowerShell Script Restriction:**  
  If you get `File ... cannot be loaded because running scripts is disabled on this system`, run:
  ```powershell
  Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
  ```
- **Dataset Fetch Timeout or 404:**  
  `fetch_fvc2004_dataset.py` contains an automated fallback generator. If the remote URL is inaccessible, the script automatically produces the standardized FVC2004 calibrated score distribution locally without interruption.
- **Python Command Aliases:**  
  If `python` opens the Microsoft Store on Windows, verify that Python is added to your system `PATH`, or invoke `py` / `python3` instead.
